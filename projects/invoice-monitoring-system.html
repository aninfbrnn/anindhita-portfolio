Invoice Monitoring System — Capstone Design and Project

A collaborative information system project addressing fragmented order, customer-document, and invoice tracking at PT Sucofindo Bandung.

PT Sucofindo · order-to-invoice workflow · SUMMARY OF TEAM REPORT

01 / OVERVIEW

Project context

The team analyzed the order-to-invoice process, where spreadsheet-based records and incomplete Purchase Order (PO) and BAST documents made tracking and coordination difficult. The report describes an implemented Invoice Monitoring System and its testing and evaluation.

02 / MY CONTRIBUTION

Individual contribution

The report identifies the team authors but does not allocate individual implementation tasks. Features, methods, and technical choices below describe the team project.

03 / KEY ACTIVITIES

Analysis, planning, and delivery

  • Mapped current and proposed order-to-invoice processes with BPMN.
  • Designed system structure and data relationships using UML and ERD.
  • Implemented order entry, PO validation, document checklists, order monitoring, approvals, and invoice management.
  • Documented validation, unit and load testing, and evaluation activities.

04 / TOOLS & METHODOLOGIES

Documented approach

Rapid Application Development (RAD)BPMN, UML, and ERDNext.js 14PostgreSQL / Neon and Google Sheets API

05 / DELIVERABLES & PROJECT PREVIEW

Team outputs

  • Invoice Monitoring System for Customer Service, Admin, and Finance roles
  • Order dashboard, document validation/checklist, and approval workflow
  • Invoice management and generation
  • Testing, validation, and evaluation documentation

Preview summarizes the academic report. It is not a claim of a production deployment or individual ownership beyond the documented role above.
