# Anindhita Febriandini - Portfolio

A responsive static portfolio highlighting my SAP and ERP practicum support, business process analysis, system documentation, research, training, organization experience, and selected academic projects.

## Run locally

Open `index.html` in a browser. The site uses relative links and assets, so keep the folder structure intact. Google Fonts load when an internet connection is available; local fallback fonts are included.

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and the root folder, then save. GitHub Pages will publish the static site from `index.html`.

## Notes

- The site is plain HTML, CSS, and JavaScript; no build step is required.
- The CV download and portfolio media are stored under `assets/`.
- Experience and case-study details are linked from the homepage and use the supplied portfolio materials.
